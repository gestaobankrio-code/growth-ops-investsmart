# Instruções de upload

1. Extraia o ZIP.
2. Suba os arquivos de dentro da pasta para a raiz do repositório `growth-ops-investsmart`.
3. Confirme que a raiz contém:

```txt
index.html
assets/
data/
scripts/
.github/
README.md
AUTOMACAO.md
```

4. Ative o GitHub Pages:

```txt
Settings > Pages > Deploy from a branch > main > / root
```

5. Em `Actions`, rode manualmente `Setup labels Growth Ops`.
6. Abra o painel e crie uma solicitação teste.
7. Após criar a Issue, aguarde o workflow `Processar Growth Ops`.
8. Atualize o painel.
